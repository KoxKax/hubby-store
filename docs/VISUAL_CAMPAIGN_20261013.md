## CMS and deployment boundaries

Three campaign images are deployment-owned render defaults only when no Owner-uploaded banner exists. Uploaded slides and legacy announcement media take priority. Explicit empty experience.slides hides the default campaign. Saved CMS snapshots, custom text, pricing, stock, warranty, user records and all revision history are unchanged. Owner can upload replacement images through the existing CMS; replacements use the existing protected media workflow. No public CMS/media schema relaxed to accept arbitrary filesystem URLs.

Product brand identification assets downloaded from official pages/CDNs; served locally so customers make no third-party image requests. Brand images apply only to exact known product ID/name pairs; custom Owner images take priority and a rename disables default logo. Source identification does not establish resale rights, partner status or unrestricted trademark license.
